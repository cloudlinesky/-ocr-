# cutbyosd — 按画面 OSD 时间截取 DVR 监控视频

DVR/NVR 导出的视频文件名中的时间往往是"导出时间",与画面内容无关;
画面左上角叠加的 OSD 时间(如 `2026-07-31 14:45:16`)才是真实录制时间。

本工具用 **OCR 自动识别每个视频的 OSD 时间**,校准出各文件在真实时间轴上的位置,
再把时间段文件中的时间段精确映射到对应视频的相对偏移,调用 ffmpeg 批量截取。
支持 **MP4** 与 **H264 / H265 裸码流**(`.h264` `.264` `.h265` `.265`)。

## 功能特性

- **自动校准**:OCR 读取 OSD 时间,不依赖文件名,自动对齐多文件时间轴
- **批量截取**:按时间段文件一次截取多个片段,输出为 MP4
- **裸码流支持**:H264/H265 裸码流自动复制封装为临时 MP4 后处理(可缓存复用)
- **图形界面**:截取 / 校准 / 文本识别 三个标签页,实时日志
- **手动校准**:校准失败或误读时,可在校准页手动修改 OSD 起点并保存复用
- **校准档案**:命名保存校准结果,换机器/换批次一键复用
- **框选 OSD 区域**:画面 OSD 位置不固定时,可手动框选提高识别率
- **便携版**:内置 Python 运行时与 ffmpeg,解压即用,无需安装

## 快速开始(普通用户)

1. 打开 [Releases](../../releases) 页面,下载最新 **cutbyosd_portable.zip**
2. 解压到任意目录(路径建议不含特殊字符)
3. 双击 **`启动.bat`** 打开图形界面

> 首次启动 OCR 较慢属正常,识别结果会缓存到视频目录的 `cache.json`,重复运行更快。

### 使用步骤

1. **视频目录**:选择存放待截取视频的文件夹
2. **时间段文件**:选择时间段 txt(格式见下);留空则按视频整段处理
3. 点 **「预览映射」** 检查校准结果与截取范围是否正确
4. 确认无误后点 **「开始截取」**,结果输出到视频目录下的 `截取\` 文件夹

### 时间段文件格式

每行一条,格式 `YYYY-HHMMSS-HHMMSS`:

```
2026-144516-144615
2026-144516-144645
```

表示 2026 年 14:45:16 ~ 14:46:15 与 14:45:16 ~ 14:46:45 两个片段。
文件默认放在视频目录下,名为 `新建 文本文档.txt`,也可在界面中选择其他文件。

### 界面说明

| 标签页 | 用途 |
| --- | --- |
| 截取 | 选择目录/时间段/输出,预览或正式截取,显示实时日志 |
| 校准 | 查看每个文件的 OSD 起点与锚点数;双击可手动修改;可保存/加载校准档案 |
| 文本识别 | 在画面任意区域用正则识别文本(如车速、车牌、GPS),用于扩展场景 |

### 常见问题

| 现象 | 处理 |
| --- | --- |
| 校准失败 / 识别不到时间 | 点「框选OSD区域」在画面上框住 OSD 时间区域,提高识别率 |
| 个别文件 OSD 起点误读 | 校准页双击该行手动修改,点「保存修改」后截取自动生效 |
| 提示 `No module named rapidocr_onnxruntime` | 请通过 `启动.bat` 启动(使用内置运行时);或自行 `pip install rapidocr-onnxruntime` |
| 裸码流第一次处理较慢 | 首次会自动封装为临时 MP4(位于系统临时目录 `cutbyosd_remux\`),之后自动复用 |
| 视频文件名无通道信息 | 「通道」留空即可;多个通道混合时填 `CH5` 之类筛选 |
| 输出片段起止偏差几秒 | 在「预览映射」中核对 OSD 起点;必要时手动校准后重试 |

## 源码运行(开发者)

需要 Python 3.9+ 与 ffmpeg(在 PATH 中或用 `--ffmpeg` 指定):

```bash
pip install -r requirements.txt
python cut_by_osd_gui.py        # 图形界面
```

或使用命令行:

```bash
python cut_by_osd.py --dir <视频目录> --txt <时间段文件> [--out <输出目录>]
                     [--ch CH5] [--ffmpeg <路径>] [--check] [--cache]
```

| 参数 | 说明 |
| --- | --- |
| `--dir` | 视频所在目录(必填) |
| `--txt` | 时间段文件(默认:目录下`新建 文本文档.txt`) |
| `--out` | 输出目录(默认:目录下`截取`) |
| `--ch` | 只使用文件名包含该通道(如 CH5)的文件 |
| `--ffmpeg` | 手动指定 ffmpeg.exe 路径 |
| `--check` | 只校准时间轴并打印映射,不执行截取 |
| `--cache` | 保存/复用 OSD 校准结果(`cache.json`) |
| `--override` | 手动校准 JSON `{文件名: OSD起点秒数}`,覆盖自动校准 |
| `--region` | 手动框选的 OSD 区域 JSON `{目录: {x,y,w,h}}`(比例 0~1) |

文本识别工具(在指定区域用正则匹配任意文本):

```bash
python matcher.py --file <视频> --t <时刻秒> --pattern "\d{1,2}:\d{2}:\d{2}" --frames 3
```

## 目录结构

```
cutbyosd/
├── 启动.bat            双击启动 GUI(便携版)
├── cut_by_osd.py       命令行核心(校准 + 截取)
├── cut_by_osd_gui.py   图形界面(tkinter)
├── matcher.py          区域文本识别工具
├── 使用说明.txt        便携版快速说明
├── requirements.txt    源码运行依赖
├── runtime/            内置 Python 3.14 + 依赖(仅便携版)
└── ffmpeg/             内置 ffmpeg.exe / ffprobe.exe(仅便携版)
```

> `runtime/` 与 `ffmpeg/` 体积较大,不在源码仓库中,请从 Releases 下载便携包。

## 系统要求

- Windows 10/11 x64
- 若 ffmpeg 无法运行,请安装 [Microsoft Visual C++ 2015-2022 Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)

## 工作原理

1. 对每个视频在不同时刻抽帧,OCR 识别 OSD 时间(支持残缺/粘连容错)
2. 用秒级锚点聚类推算文件 OSD 起点,建立"真实时间 ↔ 文件偏移"映射
3. 自动剔除时间重叠的文件,拼接成完整时间轴
4. 按时间段文件查找目标片段所在文件,计算相对偏移后用 ffmpeg 精确截取
